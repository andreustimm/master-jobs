# ADR-003: One canonical Resend sender variable

- **Status:** Accepted
- **Date:** 2026-08-25

## Context

The mailer reads `RESEND_FROM`, while `.env.example` documents
`RESEND_FROM_EMAIL`. A user can follow the example, configure a key, and still
fall back to the console mailer without realizing that production mail is not
being sent.

## Decision

Use `RESEND_FROM` everywhere: runtime, `.env.example`, deployment docs, and the
configuration contract test. Do not read both names or copy secret values into
the repository.

## Alternatives considered

- Support both names indefinitely: rejected because two names make drift easy
  and hide misconfiguration.
- Rename runtime to `RESEND_FROM_EMAIL`: rejected because deployment docs and
  the existing mailer contract already use `RESEND_FROM`.

## Consequences

The example file changes, a regression test guards the contract, and existing
deployments using the old name must be updated by the operator.
