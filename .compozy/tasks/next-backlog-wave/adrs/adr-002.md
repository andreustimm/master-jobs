# ADR-002: Register Compozy automation only after a manual run

- **Status:** Accepted
- **Date:** 2026-08-25

## Context

`job-sweep` is already validated as a loop definition, but the workspace and
automation job are not registered. Scheduling a loop before observing one real
run could repeatedly sync sources or produce unusable recommendations.

## Decision

Register the workspace, create the loop, run it manually, inspect its terminal
state and structured output, and only then create the weekday automation. The
loop may sync, score, and recommend; it must never change `application` or call
`jho track`.

## Alternatives considered

- Schedule immediately: rejected because a bad loop would repeat unattended.
- Replace the loop with cron: rejected because cron cannot perform the agent
  triage contract.
- Let the loop mutate the funnel: rejected by the product invariant that
  candidature decisions belong to the user.

## Consequences

The task has an operational, user-owned step and records evidence in the
runbook. Re-running registration must be idempotent or report the existing
resource rather than creating duplicates.
