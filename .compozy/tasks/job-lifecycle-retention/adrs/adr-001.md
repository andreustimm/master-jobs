# ADR-001 — Separate archive state from source closure

**Status:** Accepted  
**Date:** 2026-09-16

## Decision

Represent source closure with `closed_at` and operational presentation with a
separate nullable `archived_at`. Archive only confirmed old closures; never
delete a job with an application and never change application status.

## Alternatives Considered

- Delete closed jobs: rejected because it destroys candidate history.
- Reuse `application.status = archived`: rejected because it conflates source
  lifecycle with candidate decision.

## Consequences

The migration is additive and re-openable, but UI and queries must explain two
states. Physical pruning remains a separate, more conservative operation.
