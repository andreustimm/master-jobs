# ADR-001 — Fixtures plus a fail-closed ingestion guard

**Status:** Accepted  
**Date:** 2026-09-16

## Decision

Use a small synthetic fixture corpus in dev/staging and enforce a pure
environment allowlist in every ingestion entrypoint before network or queue
construction. Local network ingestion is opt-in; recurring ingestion is
production-only.

## Alternatives Considered

- Keep a reduced real sync in staging: rejected because it still spends quota
  and remains nondeterministic.
- Guard only cron configuration: rejected because direct CLI/worker invocation
  would bypass it.
- Copy production dump: rejected because it contains PII/payload debt and is
  unnecessary for product behavior.

## Consequences

Staging becomes predictable and cheap. Source connectivity needs a controlled
production canary, and fixtures must evolve with the domain.
