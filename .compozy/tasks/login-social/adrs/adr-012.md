# ADR-012: Routes, flow state and legal documents

## Status

Accepted

## Date

2026-10-06

## Context

The product uses Server Actions for forms and GET Route Handlers for callbacks (`app/login/callback/route.ts`, `redirect303`). Public paths must be registered in `proxy.ts`, `tests/architecture.test.ts` (`PAGE_POLICY`, `PUBLIC_ROUTES`), `tests/support/entry-inventory.ts` (`UNGUARDED_BY_DESIGN`), `tests/e2e/routes.mjs` and `config/e2e-spec-map.json`. The CSP has `form-action 'self'`.

## Decision

- Pages: `/signup` (single sign-up screen), `/signup/verify` (code step), `/terms`, `/privacy` — all public. Sign-in page `/login` gains the provider buttons and a "Create account" link.
- OIDC: `GET /login/oauth/[provider]?intent=signin|link&next=` starts the flow (a link, not a form POST, so `form-action 'self'` is untouched); `GET /login/oauth/[provider]/callback` completes it with `redirect303`.
- Account management: Server Actions in `app/account/` for disconnect and set-password; connect is the same `/login/oauth/[provider]?intent=link` GET, which requires a session.
- Legal documents are Markdown files `content/legal/{terms,privacy}.{pt-BR,en}.md` with a `version` (date) front matter, rendered by the two pages; the versions accepted are stored on the account (ADR-009).
- Deep links (`next`) accept only same-origin relative paths.

## Alternatives Considered

### Alternative 1: Sign-up under /login/signup

- **Description**: Reuse the `/login/*` public prefix.
- **Pros**: No new proxy entry.
- **Cons**: Less recognizable URL; Tecla-style `/signup` is the reference.
- **Why rejected**: Minor gain.

### Alternative 2: Legal text in the i18n dictionary

- **Description**: Long strings in `pt-BR.ts`/`en.ts`.
- **Pros**: One i18n mechanism.
- **Cons**: Unwieldy long-form text; no document versioning.
- **Why rejected**: Markdown with version fits better.

## Consequences

### Positive

- Clear URLs; legal text editable and versioned.

### Negative

- Four registries to update per public route (enforced by tests).

### Risks

- Open redirect through `next`: limited to relative same-origin paths and tested.

## Implementation Notes

All new UI text comes from the dictionary; pages pass 375 px and axe sweeps.
