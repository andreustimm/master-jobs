# ADR-007: One sign-up screen creates the account and the candidate profile

## Status

Accepted

## Date

2026-10-05

## Context

Today a new candidate account lands on a separate "create my profile" onboarding (name, headline, CV pasted or uploaded as PDF). The owner pointed to Tecla's sign-up (`app.tecla.io/t/signup`) as the reference: one screen with name, email, password, CV upload, terms acceptance, "Sign up" and "Sign up with LinkedIn", next to a brand panel, so that sign-up already completes the first onboarding step.

## Decision

- A single sign-up screen, with a brand panel beside the form on wide screens and stacked on narrow screens, offers "Continue with Google", "Continue with LinkedIn" and the manual form.
- The form asks: role (Candidate or Recruiter); name; for candidates, headline and CV (PDF upload with the current size limit and text-layer check, or pasted text with the current minimum length); email and password (manual path only); acceptance of the Terms of Use and Privacy Policy.
- On the social path the person first completes the provider consent and returns to the same screen with the verified email shown and no password field; one submit creates the account (and, for candidates, the profile with the CV as its first version).
- On the manual path, submit sends the code (ADR-006); entering the code creates the account and the profile with what was submitted.
- Nothing is created until the final step succeeds; a failure in CV processing is shown on the screen and keeps the other fields filled.
- The existing "create my profile" onboarding remains for accounts created by administrators without a profile.

## Alternatives Considered

### Alternative 1: Sign-up then separate onboarding

- **Description**: Short sign-up, then the existing onboarding page.
- **Pros**: Reuses the page unchanged.
- **Cons**: Two steps; the owner prefers Tecla's single screen.
- **Why rejected**: Owner's choice.

### Alternative 2: Single screen with optional CV

- **Description**: Same screen, CV can be skipped.
- **Pros**: Faster sign-up.
- **Cons**: Profiles without CV cannot be scored.
- **Why rejected**: The owner chose CV as part of sign-up for candidates.

## Consequences

### Positive

- A candidate is ready to receive scored jobs right after sign-up.

### Negative

- The sign-up screen is longer than a pure sign-in.

### Risks

- Large PDF uploads on slow connections: the screen shows progress and keeps fields on failure.

## Implementation Notes

The CV becomes the candidate's first CV version, exactly as the current onboarding does. Terms acceptance records the document versions and the time.
